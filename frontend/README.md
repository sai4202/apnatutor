# ApnaTutor — Frontend

Next.js app for the ApnaTutor tutor marketplace.

A self-contained project: it builds and runs from this directory alone, and reaches the backend only over HTTP.

## Stack

| | |
|---|---|
| Framework | Next.js 16.3.3 (App Router) |
| UI | React 19.2.8 |
| Styling | Tailwind CSS 4 |
| Language | TypeScript (strict) |

## First-time setup

**1. Install** — Node.js 24 LTS or newer.

```powershell
npm install
```

**2. Configure.** Copy `.env.example` to `.env.local`. The default points at the backend on `localhost:8080` and needs no change for local work.

**3. Run.**

```powershell
npm run dev
```

UI on `http://localhost:3000`.

The backend must be running for pages to load data — start it with `cd ..\backend; .\mvnw.cmd spring-boot:run`. The home page shows a system-check panel reporting whether the backend and its database are reachable, so a blank or degraded page tells you immediately which side is down.

## Next.js 16

Next 16 differs from most training data and older tutorials. Authoritative docs ship inside the repo at `node_modules/next/dist/docs/` — read those rather than relying on remembered App Router conventions.

`AGENTS.md` and `CLAUDE.md` are partly generated by `next dev`. Leave them committed; deleting only recreates an uncommitted change.

## Conventions

- **Server Components by default.** `"use client"` only where interactivity requires it.
- **SEO pages must render fully without JavaScript.** The programmatic city×subject pages are the product's primary acquisition channel, so an empty client-rendered shell defeats the whole strategy. Verify with JS disabled.
- **Read the API base URL from `src/lib/api.ts`**, never `process.env` directly.
- **Branch on `ErrorCode`, never on message text.** Codes are a stable contract; messages get reworded.
- **Filter and search state lives in the URL** so results are shareable and the back button works.
- **Mobile-first** — assume a mid-range Android phone on a slow connection.
- `NEXT_PUBLIC_*` is compiled into the browser bundle. Never put a secret behind that prefix.

## Contact details are the product

The API masks tutor and student contact details until a lead is paid for and unlocked. The UI must never reconstruct, cache, log or display a phone number outside an unlocked lead. Treat any leak as a P0.

Full rules: [`../docs/SOURCE_OF_TRUTH.md`](../docs/SOURCE_OF_TRUTH.md).
